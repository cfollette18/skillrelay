# Third-party design assets

The console uses Namakan's oat/navy/lava theme direction, adapted at the owner's request. SkillRelay retains its own name and components. No Namakan application logic or private research data is included.

Navigation icons are the regular Phosphor Icons paths, licensed under MIT. The license is included in `src/skillrelay/assets/PHOSPHOR-LICENSE.txt`.

Cabinet Grotesk is loaded from the official Fontshare API for Namakan's typography. Font files are not redistributed in this repository. If that service is unavailable, the console uses the system sans-serif fallback. Fontshare's font license is separate from SkillRelay's MIT source license.
